# Privacy Policy — Personal Trainer (Private Single-User Application)

_Last updated: 2026-07-07_

This application ("Personal Trainer") is a **private, non-commercial, single-user application** operated exclusively by and for its sole developer and user, Manuel Rocholl. It is not offered to the public, has no other users, and processes no third-party personal data.

## What data is processed

With the explicit authorization of the sole user via Oura's OAuth2 consent flow, the application retrieves that user's own health and activity data from the Oura API (including sleep, readiness, activity, heart rate and related metrics).

## How data is stored and used

- All retrieved data is stored in a **private local database** on hardware owned and controlled by the user.
- Data is used solely to provide personal fitness and health insights to the user himself.
- Data is **never sold, shared, published, or transferred to third parties**.
- Portions of the data may be processed by the Anthropic API (Claude) to generate personal training recommendations, subject to Anthropic's data processing terms.

## Data retention and deletion

The user has full control over the database and may delete any or all data at any time. Revoking API access via Oura's account settings stops all further data retrieval.
